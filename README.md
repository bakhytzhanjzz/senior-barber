# Senior Barbershop — сайт и онлайн-запись

Next.js 16 + Tailwind + Supabase. Сайт на русском и казахском (`/ru`, `/kk`), онлайн-запись (`/ru/booking`) и панель для персонала (`/admin`).

## Запуск

```bash
npm install
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000) — по умолчанию редиректит на `/ru`.

Без Supabase сайт полностью работает в demo-режиме: каталог услуг статичный, запись симулируется без сохранения, админка показывает заглушку. Это удобно для просмотра дизайна, но для реальной работы (сохранение записей + панель для барбера/менеджера) нужно подключить Supabase (ниже).

## Подключение Supabase (обязательно для реальной записи и админки)

1. Создать проект на [supabase.com](https://supabase.com) (бесплатного тарифа достаточно для старта).
2. Открыть **SQL Editor** → **New query**, вставить содержимое `supabase/schema.sql` и нажать **Run**. Это создаст таблицы, защиту доступа (RLS) и заполнит услуги/точки/часы работы стартовыми данными.
3. В **Project Settings → API** скопировать `Project URL` и `anon public` ключ.
4. Скопировать `.env.local.example` в `.env.local` и вставить туда эти два значения.
5. Перезапустить `npm run dev` — сайт и запись теперь пишут в реальную базу.

### Номер WhatsApp

В таблице `locations` поле `whatsapp` уже заполнено номером `77759090996` (без `+`). Поменять его можно прямо в Supabase: **Table Editor → locations**.

### Доступ в админку

Панель `/admin` защищена входом Supabase Auth. Чтобы завести первого сотрудника:

1. **Authentication → Users → Add user** — создать пользователя с email/паролем.
2. В **SQL Editor** выполнить (подставив реальный UUID пользователя):
   ```sql
   insert into staff (user_id, location_id, full_name)
   values ('<uuid пользователя>', null, 'Владелец');
   ```
   `location_id = null` даёт доступ ко всем точкам сразу; чтобы ограничить сотрудника одной точкой — подставить её `id` из таблицы `locations`.
3. Войти на `/admin` тем же email/паролем.

В админке: список записей по всем точкам или с фильтром по одной, смена статуса (подтвердить / завершить / отменить / не пришёл).

## Структура

- `src/app/[locale]` — сайт (лендинг, `/booking` — визард записи), локали `ru`/`kk`
- `src/app/admin` — панель персонала (вход + список записей)
- `src/lib/data` — тексты и цены услуг, адрес точки (правится прямо в коде — просто TypeScript-файлы)
- `src/lib/i18n/dictionary.ts` — все тексты интерфейса на русском и казахском
- `supabase/schema.sql` — схема базы, политики доступа, стартовые данные

## Изменить цены, услуги, часы работы

Быстрее всего — прямо в Supabase (**Table Editor**) после подключения: изменения появятся на сайте сразу, без деплоя. Тексты услуг на лендинге (`src/lib/data/services.ts`) используются как запасной вариант, пока Supabase не подключён — их тоже можно поправить и передеплоить при необходимости.

## Деплой

Обычный Next.js проект — подходит [Vercel](https://vercel.com/new) (проще всего: импортировать репозиторий, добавить те же переменные `NEXT_PUBLIC_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_ANON_KEY` в настройках проекта, деплой автоматический).
